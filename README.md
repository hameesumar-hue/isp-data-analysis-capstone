# ISP Data Analysis Training Capstone Project

## Project Overview
This project involves cleaning, organizing, and analyzing a Billionaires Statistics dataset using Microsoft Excel. The aim is to explore the distribution of billionaires by country, industry, age group, and net worth.

## Tools Used
- Microsoft Excel
- Data cleaning and transformation
- Descriptive statistics
- PivotTables and charts

## Data Cleaning
The data preparation process included:
- Removing duplicate records.
- Standardizing gender categories.
- Converting GDP values into numeric format.
- Creating date of birth and age calculations.
- Preparing the dataset for analysis.

## Key Areas of Analysis
- Top 10 richest billionaires by net worth.
- Countries with the highest numbers of billionaires.
- Industries with the highest numbers of billionaires.
- Distribution of billionaires by age group.
- Descriptive statistics for net worth and age.
- Average country life expectancy associated with the top 20 billionaires.

## Key Findings
The analysis identified the United States as the country with the highest number of billionaires in the dataset. Finance & Investments was the industry with the highest billionaire count. The net-worth analysis also showed a substantial difference between the wealthiest individuals and the rest of the group.

## Project Files
- Excel workbook containing the cleaned data, descriptive statistics, PivotTables, and charts.

## Conclusion
This project demonstrates the use of Microsoft Excel for data cleaning, descriptive analysis, summarization, and visualization.
